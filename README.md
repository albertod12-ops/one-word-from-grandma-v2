One word a grandma would text about AI: "Rob" — she thinks the AI is a man named Rob, and texts him like an old friend. Warm, baffled, and the whole joke lands in three letters: grandma never feared the machine, she just befriended it and gave it a name — and the name is accidentally right, because Rob is short for robot.

## Run it

```sh
python3 main.py
```

Output: `/output/entry.txt` containing exactly `Rob` — 3 bytes, no
trailing newline.
